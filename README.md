## 📖 Descrição

Plataforma web desenvolvida para uma empresa especializada na venda de embarcações, focada na exibição de catálogo, especificações técnicas e contato comercial.

## 🚀 Tecnologias

### 🌐 Frontend

- ⚙️ JavaScript
- 🎨 CSS
- 🛠️ HTML
- 🟪 Bootstrap

## 🎯 Features

- Catálogo de Embarcações
- Detalhes Técnicos
- Formulário de Contato
- Importação e Exportação de Embarcações em CSV
- Design Responsivo
- Validação de Formulários
